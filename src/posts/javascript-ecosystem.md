The churn has settled. Biome has largely replaced ESLint + Prettier for new
projects, and most bundlers now speak each other's plugin formats. Vite remains
the standard dev server, with Rolldown powering the next generation of
production builds.

Server-side runtime diversity is the real story: Node, Deno, Bun, and
WinterCG-compatible edge runtimes mean you write once and deploy anywhere — as
long as you stick to Web APIs.
